本リポジトリは、ポートフォリオ掲載作品のソースコード共有用リポジトリです。
作品の全容・デモ動画・概要につきましては、[ポートフォリオ](https://mkaoy-portfolio.vercel.app/works/B2_CG.html)をご覧ください。

## 画像アセットについて

著作権・ライセンス保護のため、使用している画像ファイルは本リポジトリに含まれておりません。
**実行時には、お手元で画像を用意して `data/` フォルダを作成し、以下のように配置してください。**

- **魚のテクスチャ**（配置先: `data/fish_texture.png`）
- **床のテクスチャ**（配置先: `data/yuka.jpg`）

※ `data/` フォルダ内に上記画像ファイルが存在しない場合、`loadImage()` で読み込みエラー（NullPointerException）が発生しプログラムが停止する場合がありますのでご注意ください。
